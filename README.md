# Birthday Invitation

## English

A static web page built as a digital birthday invitation, hosted on iCloud and integrated with Apple ecosystem services.

### Features
- Apple MapKit integration to show the event location
- Apple MusicKit integration for background music
- Calendar event (`.ics`) to add the party to guests' calendars
- Responsive layout with custom CSS and fonts

### Tech Stack
- HTML5, CSS3, JavaScript (vanilla)
- Apple MapKit JS
- Apple MusicKit JS
- iCloud Invites platform

### How to run
Open `index.html` in a browser. Some Apple API features require valid tokens and may only work fully when served from the iCloud Invites platform.

## Italiano

Pagina web statica realizzata come invito digitale di compleanno, ospitata su iCloud e integrata con i servizi dell'ecosistema Apple.

### Funzionalità
- Integrazione con Apple MapKit per mostrare la posizione dell'evento
- Integrazione con Apple MusicKit per la musica di sottofondo
- Evento calendario (`.ics`) per aggiungere la festa al calendario degli ospiti
- Layout responsive con CSS e font personalizzati

### Stack tecnologico
- HTML5, CSS3, JavaScript (vanilla)
- Apple MapKit JS
- Apple MusicKit JS
- Piattaforma iCloud Invites

### Come eseguire
Apri `index.html` in un browser. Alcune funzionalità Apple API richiedono token validi e potrebbero funzionare completamente solo se servite dalla piattaforma iCloud Invites.
